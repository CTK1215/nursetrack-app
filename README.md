# nursetrack-app — NurseTrack marketing site

Static landing page for [NurseTrack](https://nursetrack.app) — AI charting,
route optimization, mileage and pay tracking for home-health nurses.

Plain HTML/CSS, no build step. Deployed on Vercel (`cleanUrls` enabled).

- `index.html` — landing page
- `privacy.html` — Privacy Policy (served at `/privacy`)
- `terms.html` — Terms of Service (served at `/terms`)
- `styles.css` — Deep Azure theme (matches the mobile app's palette)
- `assets/` — wordmark + app icon imagery
